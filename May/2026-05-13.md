### 강의

1. 5단 분석법
    - 일반명사
        - 기초 이해 제공
    - 고유명사
        - 구체적인 지식 습득
    - 사용이유
        - 중요성 이해
    - 사용방법
        - 실제 적용 학습
    - 다른 기술과의 비교
        - 비판적 사고 촉진
2. 컴퓨터언어
    - compute + er 
        - 초창기에는 직업(계산하는 사람)을 나타내는 언어였음.
        - 계산기 등장 이후 특정 기계를 가르키는 표현으로 굳어짐.
3. Java 응용
    - 개발 배경
        - 하드웨어 제어 방식이 제조사마다 달랐음.
        - C언어가 주류인 상태에서는 각각의 하드웨어에 맞춰 개발을 진행해야 했음.
    - 원리
        - 일종의 통역 역할을 하는 JVM 을 두어 하나의 코드로 각각의 하드웨어를 사용할 수 있게 함.
    - 특징
        - 플랫폼 독립성
            - 중간단계(바이트코드) 거쳐서 어디든 실행
                - 바이트 코드는 플랫폼에 상관없이 동일하게 출력됨.
                - 해당 바이트코드를 JVM 위에서 동작시키는 것
        - 보안 안정성
            - 격리된 환경에서 프로그램 실행
        - 자동 메모리 관리
            - GC, 힙, 스택
        - 객체 지향언어
    - JVM
        - 자바의 바이트코드를 기계어로 번역해서 실행하는 엔진
        - OS로 부터 메모리 할당 받음.
            - 메모리 관리를 하는 주체
    - JRE
        - 자바 프로그램을 실행하기 위한 최소한의 환경
        - JVM + 클래스 라이브러리 (기본 부품)
        - 자바 프로그램이 돌아가려면 JVM 만으로는 부족하다.
        - String, System, Package 등 기본 클래스 라이브러리
    - JDK
        - 바이트코드를 만들기 위해 -> 바이트코드가 없는경우 JRE 만으로 실행이 불가능
        - JRE + 개발용 도구(Javac, 디버거 등)
    - 메모리 관리
        - 스택
            - 각 스레드마다 별도로 할당되는 메모리
        - 힙
            - 모든 쓰레드들이 공통적으로 사용하는 메모리
        - GC
            - 힙 영역에서 더 이상 참조되지 않는 객체를 자동으로 정리하는 기능
            - Python의 Reference Counting 과의 차이점?
                - 즉각적으로 해제되는 Reference Counting 방식과 달리 너무 잦은 해제 할당을 예방할 수 있음.
                - 대신 메모리 사용량은 높을 수 있음.
                - Stop the world 같은 문제가 발생할 수 있음
        - 스택과 힙을 나누는 이유
            - 효율성
            - 스택은 사용이 끝나면 즉각적으로 해제
            - 힙은 오랫동안 들고 있어야하는 자료를 보관
    - 타입
        - 기본형 타입 (지역변수의 경우 스택에 저장)
            - 논리형
                - boolean
            - 문자형
                - char
            - 정수형
                - byte
                - short
                - int
                - long
            - 실수형
                - float
                - double
        - 참조형 타입 (실제 데이터는 힙에 저장되고 주소는 스택에 저장)
        - String Constant Pool
            - 동일한 문자열을 heap 에 한번만 사용하기 위한 pool

### 키워드 한줄정리

- 컴퓨터언어
    - 사람이 컴퓨터에게 명령을 내리기 위한 언어?
- 자바
    - 플랫폼에 독립적이고 JVM 이라는 격리된 환경안에서 동작하기 때문에 보안성이 좋은 객체지향 언어.
- JDK(Java Development Kit)
    - JRE를 포함하는 자바를 개발할 수 있는 도구
- JRE(Java Runtime Environment)
    - 자바 프로그램을 실행할 수 있는 최소한의 도구 (JVM + 기본 라이브러리)
- 바이트코드
    - 자바 코드를 컴파일 하면 나오는 중간단계 코드이고 JVM 에서 읽어서 기계어로 번역해서 사용
- GC
    - 힙 영역을 알고리즘에 따라 주기적으로 메모리 해제하는 도구
- 스택
    - 각각의 쓰레드에 할당되는 메모리 영역
- 힙
    - 모든 쓰레드들이 사용하는 메모리 영역
