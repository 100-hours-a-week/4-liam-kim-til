# Class Notes(Cloud)

## 2026-05-26 (day 9)

### 강의

1. 데이터베이스
    - 기본 특징
        - 중앙 집중 관리
            - 데이터를 한 곳에서 일관되게 관리하여 중복과 불일치 감소
        - 효율적 검색
            - 인덱스와 최적화 기능으로 대용량 데이터의 빠른 조회 지원
        - 높은 보안성
            - 사용자 권한, 인증, 접근 제어를 통한 민감 정보 접근 제한
        - 동시성 제어
            - 다중 사용자 동시 접근 환경에서 데이터 충돌 방지 및 안전한 트랜잭션 처리
        - 무결성 제어
            - 제약조건(기본키, 외래키, NOT NULL 등)으로 데이터 정확성/일관성 보장
        - 호환성
            - 표준 SQL 및 드라이버 기반으로 다양한 애플리케이션/시스템 연동 지원
    - 트랜잭션과 ACID
        - 원자성(Atomicity)
            - 트랜잭션의 모든 작업이 완전히 반영되거나 전혀 반영되지 않음
        - 일관성(Consistency)
            - 트랜잭션 전후 데이터가 정의된 규칙과 제약을 항상 만족
        - 고립성(Isolation)
            - 동시에 실행되는 트랜잭션 간 중간 상태 간섭 차단
        - 지속성(Durability)
            - 커밋 완료 결과가 장애 발생 후에도 유지
    - SQL
        - DDL(Data Definition Language)
            - 테이블/스키마 등 데이터 구조 정의·변경·삭제
        - DML(Data Manipulation Language)
            - 데이터 조회·삽입·수정·삭제
        - DCL(Data Control Language)
            - 권한 부여/회수 등 접근 제어 수행
    - 관계 모델링(ERD)
        - 식별 관계
            - 부모 엔터티 기본키가 자식 엔터티 기본키에 포함되는 강한 관계
        - 비식별 관계
            - 부모 엔터티 기본키가 자식 엔터티의 일반 외래키로만 존재하는 약한 관계
    - 인덱스
        - B-Tree
            - 정렬된 균형 트리 구조
            - 탐색/삽입/삭제 시간복잡도 O(log n)
            - 범위 검색과 정렬 기반 조회에 유리
        - B+Tree
            - 데이터 참조가 리프 노드에 집중된 구조
            - 리프 간 연결로 순차/범위 검색 성능 우수
            - 탐색 시간복잡도 O(log n)
        - Hash Table
            - 해시 함수 기반 키-값 탐색 구조
            - 평균 탐색/삽입/삭제 O(1)
            - 해시 충돌이 많으면 최악 O(n)
        - Full-Text Index
            - 자연어 텍스트 검색 전용 인덱스
            - 단순 LIKE 대비 검색 품질/성능 개선
            - Stop Word Parser
                - 의미가 낮은 불용어 제거로 인덱스 크기 감소 및 검색 효율 개선
            - N-gram Parser
                - 문자열을 n글자 단위로 분해하여 부분 일치/초성 유사 검색 지원
            - MeCab
                - 형태소 분석 기반 파서
                - 한국어/일본어의 어절·품사 단위 분석으로 검색 정확도 개선
    - 트랜잭션
        - 하나의 논리적 작업 단위로, 전부 성공 또는 전부 실패가 보장되어야 함
        - Active
            - 트랜잭션이 실행 중인 상태
            - SQL 수행, 데이터 읽기/쓰기, 락 획득 등이 진행되는 구간
        - Partially Committed
            - 마지막 SQL까지 실행했지만 아직 최종 커밋 전 상태
            - 장애 발생 시 롤백 가능하므로 결과 확정 전 단계
        - Failed
            - 오류, 제약조건 위반, 시스템 장애 등으로 정상 진행이 불가능한 상태
            - 이후 복구를 위해 롤백 단계로 이동 필요
        - Aborted
            - 롤백이 완료되어 트랜잭션 변경사항이 모두 취소된 상태
            - 필요하면 처음부터 재시도 가능
        - isolation level
            - 동시 실행 트랜잭션 간 간섭을 어디까지 허용할지 정하는 격리 강도
            - 격리 강도가 높을수록 정합성은 좋아지지만 동시성/성능은 낮아질 수 있음
            - Read Uncommitted
                - 커밋되지 않은 데이터까지 읽기 허용
                - Dirty Read, Non-repeatable Read, Phantom Read 모두 발생 가능
            - Read Committed
                - 커밋된 데이터만 읽기 허용
                - Dirty Read 방지, Non-repeatable Read/Phantom Read 발생 가능
            - Repeatable Read
                - 같은 조건으로 재조회 시 기존 행 값의 일관성 보장
                - Dirty Read, Non-repeatable Read 방지, Phantom Read는 DB 구현에 따라 가능
            - Serializable
                - 트랜잭션을 순차 실행한 것과 같은 최고 격리 수준
                - Dirty Read, Non-repeatable Read, Phantom Read 방지, 대신 동시성 저하 가능
            - 이상 현상 정리
                - Dirty Read: 다른 트랜잭션의 미커밋 데이터를 읽는 현상
                - Non-repeatable Read: 같은 행을 다시 읽었을 때 값이 달라지는 현상
                - Phantom Read: 같은 조건 재조회 시 행의 개수가 달라지는 현상
2. 키워드 정리
    - 데이터베이스
        - 데이터를 저장/관리하고, 필요할 때 빠르고 안전하게 꺼내 쓰기 위한 시스템
    - ERD
        - 데이터 간 관계를 그림으로 표현해 테이블 구조와 연결 방식을 설계하는 도구
    - Index
        - 원하는 데이터를 전체 탐색 없이 빠르게 찾게 해주는 데이터 구조
    - Tree 와 Hash
        - Tree는 범위/정렬 검색에 강하고, Hash는 정확히 일치하는 값 검색에 빠른 구조
    - Full Text Index
        - 텍스트를 단어 단위로 분석해 검색을 빠르게 하는 인덱스
    - Transaction
        - 여러 작업을 하나로 묶어 전부 성공하거나 전부 실패하게 보장하는 실행 단위
