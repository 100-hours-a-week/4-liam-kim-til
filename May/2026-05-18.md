    - http(HyperText Transfer Protocol)
        - 웹에서 클라이언트와 서버가 데이터를 주고받기 위한 통신 규약
        - Stateless(무상태): 서버가 각 요청을 독립적으로 처리한다.
        - 클라이언트
            - 요청하는 주체
            - 예: 브라우저, 모바일 앱, 프론트엔드 애플리케이션
        - 서버
            - 응답(데이터/기능)을 제공하는 주체
            - 요청을 받아 처리한 뒤 결과(HTML, JSON, 이미지 등)를 반환한다.
        - Method
            - GET, HEAD, POST, PUT, PATCH, DELETE 등
            - 요청에 대한 성격(등록인지 수정인지 삭제인지 등)
        - status code
            - 1xx: 정보 응답, 2xx: 성공, 3xx: 리다이렉션, 4xx: 클라이언트 오류, 5xx: 서버 오류
    - https
        - HTTP + TLS(암호화) 조합
        - 목적: 기밀성(암호화), 무결성(변조 방지), 인증(서버 신원 확인)
    - https 에서 키 교환 방식에 대해 설명
        - 핵심 아이디어: 공개키 암호화로 안전하게 "대칭키(세션키)"를 합의하고, 실제 데이터 전송은 빠른 대칭키로 암호화
        - TLS Handshake(간단 흐름)
            - 1) ClientHello: 클라이언트가 지원 가능한 TLS 버전/암호 스위트/난수 전송
            - 2) ServerHello: 서버가 사용할 암호 방식 선택 + 서버 인증서(공개키 포함) 전달
            - 3) 인증서 검증: 클라이언트가 CA 체인/도메인/유효기간 확인
            - 4) 키 교환: (주로 ECDHE) 양쪽이 임시 키 교환값을 주고받아 같은 세션키를 계산
            - 5) Finished: 이후부터 애플리케이션 데이터는 세션키로 암호화되어 전송
        - 참고
            - 공개키(비대칭키): 키 합의/인증에 사용
            - 대칭키(세션키): 실제 HTTP 데이터 암복호화에 사용(속도가 빠름)
    - Query String
    - Path Variable
    - RESTful
        - URI는 자원을 표현한다
        - 자원에 대한 행위는 http method로 표현한다
        - 자기자신에 대한 설명이 있어야함.

    - Bean

        - 컨테이너가 관리한다는 의미
            - 객체 생성
            - 의존성 주입(DI)

            - Bean이어야 @Autowired, AOP, 트랜잭션 같은 스프링 기능 적용 가능
3. 한줄정리
    - Web: 인터넷에서 정보를 주고 받는 공간
    - 클라이언트: 서버에 요청을 보내는 주체(브라우저, 앱)
    - 서버: 요청을 처리하고 데이터/기능을 응답하는 주체
    - HTTP: 웹에서 클라이언트-서버가 통신하는 요청/응답 기반 프로토콜
    - HTTP message: 시작줄 + 헤더 + 본문으로 구성된 HTTP 데이터 형식
    - HTTP Method: HTTP 요청에 대한 대략적인 성격을 나타내는 것
    - HTTP Status Code: 요청에 대한 응답 결과를 코드로 나타낸 것
    - HTTP URL: 자원의 위치와 접근 방식을 나타내는 주소 체계
    - Query String: URL 뒤에 추가 정보를 전달하기 위한 문자열
    - Path Variable: URL 경로 자체에 자원 식별값을 포함하는 것
    - RESTful API: HTTP 관련 통신을 잘 사용하기 위한 규칙 혹은 메뉴얼
    - Spring: 자바에서 객체 관리와 의존성 주입등을 지원하는 프레임워크
    - IoC: 객체 생성/제어 권한을 개발자 코드에서 컨테이너로 넘기는 개념
    - DI: 코드 결합도를 낮추기 위한 의존성 주입 방식
    - AOP: 로깅/트랜잭션 같은 공통 관심사를 핵심 로직과 분리하는 기법
    - Spring bean: 스프링 컨테이너에 등록되어 생성/주입/생명주기 관리를 받는 객체
    - Bean Container: Bean을 생성, 보관, 주입, 생명주기까지 관리하는 스프링 컨테이너
